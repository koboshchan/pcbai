This experiment classifies isolated spoken digits zero through nine with 64 inputs, 16 rectified hidden neurons and 10 outputs. It uses Google Speech Commands v0.02 under CC BY 4.0, credited to Pete Warden / Google. The official compressed archive SHA-256 and official split-list hashes are recorded in dataset_provenance.json. Only digit WAVs and split metadata are retained locally. No dataset is committed.

Run python3 training/spoken_digits/prepare.py followed by python3 training/spoken_digits/train.py on KAT-BOX only. For the new layouts, pass --layouts 4x16 4x16-alt to both scripts. Dependencies are Python 3.12, NumPy, SciPy, PyTorch with CUDA, Pillow and PyArrow (the latter two are imported by the existing fixed-model definition loader). The download needs enough room for a streamed 2.3GB archive and about 1.3GB of retained digit audio. No archive is stored. An initial extraction bug skipped ./-prefixed metadata; the corrected extraction was rerun and the archive checksum matched the official value.

Each 16kHz mono clip is trimmed or right-zero-padded to one second. Features use a 512-point STFT, 400-sample Hann window and 160-sample hop, power spectra, triangular mel bands spanning 20Hz to 8kHz and log10 power floored at 1e-10. Frames are partitioned into eight or four consecutive bins and averaged, then flattened band-major. This gives either 8 bands × 8 time slices or 16 bands × 4 slices. Per-feature 1st/99th percentiles are fitted on training clips only; values are clipped to 0..1, rounded to 63 duty steps and converted to 0..5V. Exact scaling constants are saved in preprocess_*.json. Official splits give 31,158 training clips, 3,643 validation clips and 4,107 test clips. Speaker IDs are disjoint across these splits.

All float baselines use Linear(64,16), ReLU and Linear(16,10), Adam at 0.0015 for 60 epochs, seed 42064 and validation-only checkpoint selection. Each hardware model starts from its corresponding float checkpoint and receives another 60 epochs. It reuses the existing fixed_model/train.py Net definition verbatim, with differential E24 resistor conductances, E96 balance resistors, shared source-loading KCL, active rectifier/clipping, QAT from zero-based epoch 15 and tolerance training from epoch 25. This means the hardware model has more training epochs than the baseline; its higher accuracy is not evidence that quantization itself improves recognition. Neither architecture nor the existing MNIST board population was changed.

The unchanged fixed_model/cuda_mc.py solver evaluates 1,000 boards per layout, seed 51005, on all test clips. Weight/bias resistors and the shared 10k input source resistors vary ±5%; feedback, balance, rectifier and ADC divider resistors vary ±1%. The fixed 50-ohm driver, 1-ohm follower, 13.5V swing, 12-bit ADC and 6-bit inputs are retained. Nominal plus three random boards agree with the NumPy physical solver within 1e-9V for score/hidden values and 1e-12V for ADC values. Monte Carlo samples are resistor-tolerance simulations, not measured hardware or a certified worst case. They exclude PWM settling, microphone noise, opamp offset and unrelated/non-digit speech.

The new 4×16 front end uses causal Butterworth bandpass filters centered at 1600, 2000, 2500 and 3150Hz. Each filter has two second-order sections (fourth-order bandpass), with third-octave -3dB edges at center / 2^(1/6) and center × 2^(1/6). Filters start from zero state per clip. Mean squared amplitude is measured in sixteen nonoverlapping 1000-sample windows, each 62.5ms, then log10-transformed with a 1e-10 power floor. This is log power, not a rectified analog-envelope circuit simulation. It is equivalent to twice log10 RMS before scaling, with the corresponding floor. Features are flattened band-major and use the same training-only percentile scaling and six-bit quantization as the earlier layouts.

The requested 1600/2000/2500/3150Hz model scores 44.56% float and 45.61% nominal hardware on test. Across 1,000 tolerance boards it averages 44.53%, with a 42.59% minimum and 43.75% fifth percentile. The 4×16-alt model changes only the centers to 500/1000/2000/4000Hz. It scores 57.63% float and 60.56% nominal hardware, with a 59.82% tolerance mean, 58.19% minimum and 58.92% fifth percentile. Endpointing uses DC-removed wideband power in 20ms windows at a 10ms hop. The threshold is the maximum of four times the clip's 20th-percentile frame energy, 4% of its peak frame energy and 1e-7 full-scale squared. Only runs of at least three consecutive above-threshold frames count. The interval spans the first through last qualifying run, retaining internal pauses, with 30ms margins and a minimum 80ms duration. If no run qualifies, the whole clip is retained. Silence, stationary noise and continuous high-energy speech therefore fall back safely to the original window rather than creating an empty clip. This is an energy endpoint detector, not a general speech/noise classifier; nonstationary noise can still fool it.

The retained interval is stretched in feature time, not by resampling the waveform. Uniform relative-time bins cover the entire selected interval with fractional-cell integration. The 8x8 variant pools the existing mel log-power frames, whose timestamps use the 10ms STFT hop; the 4x16 alternative pools the existing causal 500/1000/2000/4000Hz filter powers and then takes log10. Filters and STFT are computed on the original one-second audio, preserving pitch, original frequency bands and pre-onset filter history. Actual waveform resampling would shift digit spectra and test a different front end. The only intended change here is temporal alignment; STFT support still extends around frame centers, so mel endpoint precision is limited by its 25ms window.

The 400ms augmentation experiment is separate from the alignment runs above. Its corrected labels are 4x16-alt-aug400-silence and 8x8-aug400-silence; summary400_silence.json does not change the legacy summary schema. Run train400.py on the existing KAT-BOX cache. It completes the four-band model before preparing or training eight-band. Both keep 64 inputs, 16 hidden neurons, 10 outputs, seed 42064, 60 float plus 60 hardware epochs and the existing physical QAT/resistor solver.

Every window is exactly 6400 samples at 16kHz. Raw detected_region bounds are used without the earlier 30ms margins or minimum-duration extension. A word longer than 400ms generates windows starting at its detected onset, stepping 100ms, plus a final end-aligned window if needed. A 500ms word produces two windows; exactly 400ms produces one. A shorter word produces three windows with its end, start and center aligned to the window. For short-word augmentation, every sample outside the detected word is zeroed BEFORE filtering or STFT. The three placements therefore pad with silence at the front, back or both, without admitting surrounding background or its filter history. Long-word and fallback windows retain original recording context. Padding never shifts or truncates the detected word. No detected region falls back to the full one-second interval and seven sliding windows.

There is no waveform resampling or variable-time stretching. Four-band windows contain sixteen fixed 25ms power bins from causal 500/1000/2000/4000Hz SOS filters, followed by log10. Eight-band windows contain eight fixed 50ms bins of STFT log-mel features, using fractional frame-cell pooling at the original 10ms hop. Both front ends process the full source clip with zero extensions before extracting intervals. Short-word augmented sources contain only the detected word and zeros; long-word/fallback sources and realtime single-onset evaluation keep the original audio and pre-window history. Centered STFT support extends around each frame and is not causal.

Optimization sees expanded training windows only. The scaler's 1st/99th percentiles are fitted on those expanded training windows, never validation or test. Official original identities and speaker-disjoint splits are unchanged. Validation checkpoint selection uses only single-onset 400ms accuracy for both layouts, keeping the first best checkpoint, with hardware selection restricted to QAT epochs 15 through 59. The expanded inference mode averages output scores over all windows of each original clip before choosing a class. The realtime inference mode uses one 400ms window at the detected onset. Endpoint detection still uses the recorded clip's energy statistics, so this is a single-window onset evaluation, not a tested streaming detector. Validation and test windows are never counted as additional independent examples.

Both test modes use the same 1000 resistor-board draws per layout, seed 51005, and the same 4107 original test identities. Float scores are logits and hardware scores are physical 12-bit ADC output voltages. Averaging happens before argmax, not by majority vote. Metrics include separate confusion matrices and 1000 accuracy samples for each mode, plus original-clip and window counts. test400.py checks sliding endpoints, exact duration, short-word alignment, left/right padding, fallback, frontend determinism and score grouping. check400.py checks original identities/speaker splits, reproduces all windows for 60 original WAVs across the three splits, refits the full training-only scaler and verifies selected checkpoints and exact resistor exports. These are one-training-seed experiments and tolerance simulations, not measured board accuracy.
