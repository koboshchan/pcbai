The model solves the shared 64-input KCL, including coupling through positive summer legs, rather than attenuating pixels independently. Each pin drives one 10k series resistor, then one1uF capacitor to ground and the post-filter L1 fanout. There are 8 to 14 L1 resistor branches per filtered input. Those branches do not multiply the output load by their count because the same10k input filter is in series with the whole network. The1uF is not directly connected to the595 output. Source output load is set primarily by10k, so even100ohm driver impedance only changes it by about1%.

For duty d, the averaged output term is g=d/(Rf+Rh)+(1-d)/(Rf+Rl), and its forcing term is d*VCC/(Rf+Rh). High/low asymmetry therefore changes both effective source voltage and impedance. The implementation uses three small fixed-point corrections against a low-state KCL solve, checks residuals below1e-7V, and verifies asymmetric nodes against direct NumPy solves. Driver values are fixed and coherent across64 pins for each case; they are not additional random per-pin draws.

IC supply consumption is additional to output load. TI HCT lists80uA rail-input quiescent ICC plus up to2.9mA per input under its unfavorable0.5V/2.4V test condition. With SER,SRCLK,RCLK,OE conservatively treated as four MCU-level inputs, this illustrative static budget is16.312mA, still below70mA. This2.9mA point is not a guaranteed3.3V supply-current bound. TI AHCT gives40uA ICC and1.5mA per input at3.4V, Diodes gives80uA and1.5mA atVCC-2.1V. Actual clock-frequency-dependent dynamic current must also be allowed for. The tiny analog load is not the reason to select AHCT, and a complete all-condition supply-current guarantee cannot be extracted for anonymous chips from these specs alone.

Both families have2.0V VIH and0.8V VIL at their stated5V operating conditions, so3.3V Pico logic is compatible. HCT is slower.
