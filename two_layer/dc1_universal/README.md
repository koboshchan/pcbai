Universal DC1 hand-soldered card

This is one PCB design with four population variants. It replaces the repaired DC1a, DC1b, DC1c and DC1d weight cards, not DC0, DC2, DC3 or the motherboard. All existing boards remain unchanged.

The 100 × 100 mm outline, two 3.2 mm mounting holes and 76-pad straddle connector are copied from all four existing DC1 cards and mechanically checked for exact equality, including copper side, pad shape, size, position and drill. Put the L/arrow end at the motherboard socket's pin-1 end. The arrow is on both faces.

There are 532 resistor positions, all 0805 on the top face. The complete 64-input × 4-channel matrix has 256 logical weights and 512 separate positive/negative sign options. Twenty more positions cover feedback, both bias polarities and positive/negative ground balance on every channel. No weight position is omitted just because all four current models use zero there. The 112 added positions default to DNP in every current population. Existing references and positions are preserved. Future models use the same fixed 64-input/four-channel topology, supply rails and amplifier arrangement; different dimensions or circuit architectures need another board.

The left bank holds inputs 0–31 and the right bank holds inputs 32–63. Each row is an input and each bank has eight columns, positive then negative for local channels 0–3. Resistor centers have 5.2 mm column pitch and 2.65 mm row pitch. Local channels map to global neurons 0–3 on DC1a, 4–7 on DC1b, 8–11 on DC1c and 12–15 on DC1d. Connector pins A33–A36 carry local channel outputs 0–3; the motherboard slot determines the corresponding global neuron numbers. The other 72 contacts have the same roles in every variant.

Populate each board using only its matching DC1a.csv, DC1b.csv, DC1c.csv or DC1d.csv. POPULATION.md and population_chart.pdf show the same selections by physical row and column. DNP means leave the footprint empty, an open circuit. A zero weight is never a 0 Ω link. Do not populate both alternative sign positions unless the selected variant explicitly calls for them.

DC1a uses 191 resistors, DC1b 230, DC1c 181 and DC1d 141. Every variant also uses one TL074 SOIC-14, two 100 nF 50 V 0805 rail-decoupling capacitors and the manually soldered 2 × 38 straddle header. Eight resistors on each variant require 1% tolerance; the other populated resistors use the recorded 5% tolerance. CSV values and net pairs are checked against both the source boards and their physical differential-repair manifest. The source board hashes are retained in manifest.json. These selections preserve the trained network; no retraining was performed.

Routing of the 532-site board is paused. Six initial routing variants and four continuation runs finished without a releasable board. The best error-free routed candidate has 12 unconnected items, six library-lookup warnings and 16 dangling-via warnings. The closest lower-open candidate still has clearance errors and was not adopted. The generated seed has zero DRC errors, 134 unconnected route items and six library-lookup warnings. No routed 532-site candidate has passed release verification yet. The previous 420-site candidate is archived outside this folder and is not a release of this design. This is a two-layer design with minimum 0.2 mm tracks, 0.2 mm clearance and 0.6/0.3 mm vias. No DRC exclusions were added. No board has been ordered or fabricated, and publication is awaiting approval.

Rebuild from this directory using /usr/bin/python3 build.py. Exported Specctra dc1_universal.dsn retains deliberately pre-routed front vertical summing buses and rear input rows, with vias connecting the input resistor pads. Complete the remaining connections with FreeRouting, save dc1_universal.ses, and run /usr/bin/python3 finish.py. Finish refuses release if any DRC error or unconnected item remains. Run population_chart.py to regenerate the solder chart.
